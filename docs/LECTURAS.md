# Lecturas principales de KANJŪ

Cada kanji tiene una **lectura principal**: la más frecuente en el japonés actual. Es la que suena al tocar la criatura y la única que se pide hasta **maestría 3**. Desde maestría 3, el Dojo, Lecturas y Escuchar piden también las demás.

Criterio: 訓 (kun'yomi) si el kanji se usa mucho solo o con okurigana (子 こ, 休 やす·む); 音 (on'yomi) si vive sobre todo en compuestos (時 ジ, 運 ウン). Todas son lecturas exactas del kanji, nunca palabras compuestas.
